Path-Point - бесплатная программа для генерации видео с эффектом созвездий (Plexus Effect).

Проект распространяется под лицензией Apache-2.0.


Если вы простой пользователь, не модифицируете код программы, то тогда, вам необходимы только 2 файла: 

1 - config.json, в нем хранятся все значения для работы программы, для изменения настроек симуляции, необходимо просто
изменить нужные значения в этом файле и сохранить изменения.

2 - Path_Point.exe - файл самой программой, его необходимо запустить, что бы начать создание видео и симуляцию.

Итоговое видео, вы найдете в папке video_1 которая находится внутри папки video.
Там будут находится все кадры анимации и внизу уже готовое видео.
