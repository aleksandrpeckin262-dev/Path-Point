Path-Point - open source проект для создания видео с эффектом Plexus Effect.Проект распространяется под лицензией Apache-2.0.Весь проект написан на пайтон и C, на пайтон написано 94,8% кода, а С используется для ускорения вычислений.Для изменения параметров симуляции, необходимо изменить параметры в app_config.py.Список библиотек, используемых в проекте:1 - arcade2 - random------------для рандомизации параметров3 - math--------------для более сложных вычислений4 - threading---------для многопоточности5 - os----------------для создания папок7 - ctypes------------для связи C кода и Python кода8 - time--------------для создания задержек9 - cv2---------------для склейки полученных кадровПроект состоит из нескольких файлов:1 - app_config.py - конфигурация параметров для работы проекта, размер файла - .2 - main.py - файл для запуска проекта, размер файла - .3 - logic.py - файл со всей основной логикой, размер файла - .4 - video_editor.py - файл, для склейки полученных кадров в видео, размер файла - .5 - visualizer.py - файл, для записи видео и отрисовки линий, размер файла - .6 - physics.dll - файл, берущий на себя часть вычислений (скомпилированая версия physics.c).7 - physics.c - файл, берущий на себя часть вычислений, размер файла - .В папке video, при работе проекта, создается подпапка video_1, в которой будут находится все кадры анимации, апосле видео анимации склееное из кадров.Небольшие нюансы:Стоит сообщить, что программа выжидает 20 кадров перед началом сохранения кадров, это сделано из за того, чтобез этого, успевает быть созданы пара кадров, когда окно программы еще не открыто, или только открывается.
